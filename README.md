# 凤凰知音淡旺季助手

一个无需构建工具的静态 Cloudflare Pages 页面，用于集中进入国航、深航、山航和昆航的凤凰知音官方运输奖励兑换标准。

## 本地预览

在当前目录启动任意静态服务器，例如：

```bash
npx serve .
```

也可以直接打开 `index.html` 预览页面结构；“打开官方明细”会在新标签页打开官方来源。

## Cloudflare Pages

- 构建命令：留空
- 构建输出目录：`.`
- 根目录：仓库根目录

## 数据边界

页面保存了用户提供的四个官方淡季查询入口，并提供航司选择、淡旺季切换和来源导航。当前未把里程数字或旺季 URL 硬编码进前端：官方页面可能要求登录、选择航线或随时间更新，用户应以打开后的官方明细为准。旺季切换会明确提示当前需要在官网继续核对，避免把未经验证的数据展示为规则。
